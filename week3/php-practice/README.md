## 🔍 見つけた問題点

### 1. 比較のつもりが代入になっていた

```php
if ($name = "") {   // ❌ 「=」は代入
```

- `=` は**代入**なので、`$name` が空文字 `""` で上書きされる
- 空文字は `false` として扱われるため、**if の中が実行されることはない**
- その結果、名前を入力しても空欄でも、**毎回 else 側に進む**

### 2. XSS（クロスサイトスクリプティング）の危険があった

```php
echo "<p>" . $name . "さんのコメント:</p>";   // ❌ 入力をそのまま出力
```

- ユーザーが入力した値を、何も変換せずに HTML として出力していた
- `<script>alert(1)</script>` などを入力されると、**ブラウザ上でスクリプトが動いてしまう**

### 3. 空入力のチェックが不十分だった

- チェックしていたのは名前だけで、**コメントは空のまま投稿できた**
- スペースだけの入力も、空として扱われていなかった
- 項目が送信されなかった場合、未定義のキーを参照して警告が出る可能性があった

## 🛠 修正した内容

### ✅ 1. 比較演算子に修正

```diff
- if ($name = "") {
+ if ($name == "") {
```

### ✅ 2. 出力時のエスケープでXSS対策

画面に出す直前に `htmlspecialchars()` で特殊文字を変換しました。

```php
$safeName    = htmlspecialchars($name, ENT_QUOTES, "UTF-8");
$safeComment = htmlspecialchars($comment, ENT_QUOTES, "UTF-8");

echo "<p>" . $safeName . "さんのコメント:</p>";
echo "<p>" . nl2br($safeComment) . "</p>";
```

| 入力される文字 | 変換後 |
| :---: | :---: |
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |
| `"` | `&quot;` |
| `'` | `&#039;` |

> [!NOTE]
> `nl2br()` は改行を `<br>` に変換する関数です。コメントの改行がそのまま表示されるように追加しました。
> **エスケープした後に** 使うのがポイントです（先に使うと `<br>` まで変換されてしまいます）。

### ✅ 3. 全項目の空入力チェック

```php
$name    = trim($_POST["name"] ?? "");
$comment = trim($_POST["comment"] ?? "");

$errors = [];
if ($name == "") {
    $errors[] = "名前を入力してください。";
}
if ($comment == "") {
    $errors[] = "コメントを入力してください。";
}
```

- `trim()` で前後の空白を取り除き、**スペースだけの入力も空**として扱う
- `?? ""` で、項目が送信されなかった場合も空文字として扱う
- エラーを配列にまとめ、**未入力の項目すべてのメッセージ**を表示する

## 📚 学んだこと

### `=` と `==` と `===` の違い

| 演算子 | 意味 | 例 |
| :---: | --- | --- |
| `=` | 代入 | `$a = 1;` |
| `==` | 値が等しいか比較（型は変換して比べる） | `"1" == 1` → `true` |
| `===` | 値と型の両方が等しいか比較 | `"1" === 1` → `false` |

> [!TIP]
> if の中で `=` を使ってもエラーにならないため、気づきにくいバグになります。
> 条件式を書いたら、`=` が1つだけになっていないか見直す習慣をつけたいです。

### ユーザーの入力はそのまま出力しない

- ユーザーの入力は**信用しない**のが基本
- HTML に出力するときは、必ず `htmlspecialchars()` でエスケープする
- エスケープは「保存するとき」ではなく、**「出力するとき」** に行う

> [!WARNING]
> XSS を放置すると、他の利用者の画面で勝手にスクリプトが実行され、
> ログイン情報を盗まれるなどの被害につながる可能性があります。

### 入力チェックは全項目に行う

- 必須項目は**すべて**チェックする
- 見た目は入力されていても、スペースだけのこともあるので `trim()` してから判定する
- エラーはまとめて表示した方が、利用者にとって親切

## 🧪 動作確認の方法

1. PHP のビルトインサーバーを起動する

   ```bash
   php -S localhost:8000
   ```

2. ブラウザで <http://localhost:8000/comment_fixed.php> を開く
3. 次のパターンを試す

| # | 名前 | コメント | 期待する結果 |
| :---: | --- | --- | --- |
| 1 | 空 | 空 | 両方のエラーメッセージが出る |
| 2 | 入力あり | 空 | 「コメントを入力してください。」が出る |
| 3 | スペースのみ | 入力あり | 「名前を入力してください。」が出る |
| 4 | `<script>alert(1)</script>` | 入力あり | アラートは出ず、文字としてそのまま表示される |
| 5 | 入力あり | 改行を含む文章 | 改行されて表示される |
