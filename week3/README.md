## 🚀 次に活かしたいこと

- [ ] **プロンプトを送る前に設計する**
  - Claude Codeにプロンプトを送る前に、イメージ図を描いて作りたいものの概要をある程度固めてから、プロンプトを作成する。
- [ ] **生成されたコードを検証する**
  - サーバー上で動作を確認し、どのようなパターンで入力エラーが出るかを検証する。
- [ ] **コードを自分で読んで理解する**
  - 生成されたコードの流れを自分でも読み、分からない部分があればAIに相談する。
  - コードを読む習慣をつけ、都度調べなくても理解できるようにしていきたい。
